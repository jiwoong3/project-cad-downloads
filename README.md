# Project CAD Assistant downloads

Installers and portable packages for macOS, Windows, and Linux.

[Download the latest release](https://github.com/jiwoong3/project-cad-downloads/releases/latest)

Each release includes installers, portable archives, installation instructions, and SHA-256 checksums. The macOS installer supports Apple silicon and Intel. Windows and Linux each have x64 and ARM64 packages. Every package includes its own Node runtime.

Open Project CAD Assistant, set your Project CAD website address in Settings, and set up Codex, Claude Code, or Muse. Then open the assistant in the project website and choose **Connect local assistant**.

This repository distributes application packages and release documentation. Please read the release notes for operating system requirements, signing status, and platform validation. Third-party notices are included in the packages.
